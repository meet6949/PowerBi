

Customer & Sales Intelligence Report
1. Project Objective
This project is created to analyze sales performance and customer behavior using interactive Power BI
dashboards.

2. Dataset Collection
The dataset was downloaded and reviewed to understand sales, customers, products, regions, dates,
and return information.

3. Data Import
All data files were imported into Power BI using the Get Data option and opened in Power Query Editor.

4. ETL Process
Data cleaning was done in Power Query Editor by renaming columns, fixing data types, and removing
unnecessary fields.

5. Dashboard Overview
The main dashboard shows overall sales performance, KPIs, and sales trends over time.

6. Customer Analysis Page
The customer page focuses on customer segmentation, contribution to sales, and performance using
charts and KPIs.

7. Date Table & Modeling
A proper Date table was created and relationships were built between fact and dimension tables using a
star schema model.

8. Measure Creation (DAX)
DAX measures were created for Total Sales, Total Orders, Total Units Sold, Total Returns, and average
calculations.

9. Regional Sales Map
A map visual was added to show sales distribution across different regions and identify high and low
performing areas.

10. Tooltip Analysis
Tooltip pages were designed to display detailed insights when users hover over visuals.

11. Interactivity & Filters
Slicers for date, region, product category, and customer segment were added to make the report
interactive.

12. Final Output
The final Customer & Sales Intelligence report provides clear visuals and insights to support better
business decisions.
